# A1-A2 双 MD 与空间真值

本文件由 `00-强制读取索引.md` 强制触发。进入 A1 或 A2 前必须读取本文件；未读取即触发 `[E07: Required Reference Missing]`。

## A1 故事板概要

每一集每一段必须有独立节点：

```text
故事板概要 — [集数][段落编号][场景名]
空间真值调用中心 — [集数][段落编号][场景名]
场景调度表 — [集数][段落编号][场景名]
```

A1 完成时，除生成故事板概要外，必须同时创建 `空间真值调用中心 — [集数][段落编号][场景名]` 的空骨架节点，字段可由 A2 填充。

制作前必须先读取 A0：`影视工业体系数据中心 — [集数][段落编号][场景名]`，并验证 A0 已通过 QC 且拥有 A0 `freeze_id`。缺少模板源时，必须通过 `question` 让用户选择补充模板、从剧本即时提取或暂停链路。若 A0 缺冻结记录、`freeze_id`、`content_hash_or_length_snapshot` 或 `allowed_mutation_scope`，触发 `[E08: Chain Freeze Violation]`，禁止进入 A1/A2。

故事板概要必须包含：用户原始需求、模板源摘录、已确认制作标准、本段剧情范围与结尾衔接、情绪目标、动作节拍、9 格动作概要、人物 / 场景 / 关键道具信息提取表、人物面部三庭五眼结构表、角色身份令牌表、`dialogue_intent_delivery_matrix` 继承摘要、`video_model_capability_risk_register` 继承摘要、`performance_substitution_plan` 执行摘要、Medium Lock、Avoid、下一步任务清单。9 格动作概要必须对应后续黑白 3x3 分镜的 Panel 1 至 Panel 9 顺序。

A1 不得重新判定 required dialogue 的删减、沉默化或表演替代权限；只能继承 A0 `dialogue_intent_delivery_matrix`。A1 9 格动作概要若涉及 `substitution_required: true` 的高风险动作，必须写成 A0 授权的替代表现方式，例如“起势 -> 已完成结果 -> 反应”，不得把 A0 已判定高风险的“准确实时画叉 / 写字 / 读清 UI / 复杂手部小物互动”重新写回字面实时动作。

人物面部三庭五眼结构表每个出场人物至少包含：人设 / 比例特征、面部骨相、三庭比例、五眼比例、眉弓、眼距、鼻梁、颧骨、下颌、脸型、真实皮肤细节与瑕疵、服装与阶级设定、电影级摄影参数基准。禁止只写“好看 / 清秀 / 英气 / 古风脸 / 高颜值”。

A1 完成并通过阶段 QC 后，必须把 `故事板概要 — [集数][段落编号][场景名]` 写入 A0 `[SSC_RUNTIME_LEDGER].core_doc_freeze_records` 与 `chain_freeze_manifest`：记录 `freeze_id`、`stage: A1`、节点名、上游 A0 freeze_id、`content_hash_or_length_snapshot`、允许后续变更范围仅限“版本化补丁小节 / QC 修复记录 / 下游引用 id”，并把 A1 `freeze_id` 回填到本段全部受影响的 `video_task_mapping[video_task_id].stage_freeze_ids`；禁止后续阶段原地压缩、摘要、删改或用“同上 / 已继承”替代其中剧情、人物、动作、对白矩阵、能力边界和 Avoid。A1 完成后必须标记 `Narrative Capacity Recalibration Pending`，因为 A1 的剧情范围、9 格动作概要、人物 / 场景 / 道具信息、情绪目标和动作节拍可能推翻 A0 的剧本初算。该标记必须在 A2 / A5 前被处理。

## A2 场景调度表与空间真值

A2 必须同时产出：

```text
场景调度表 — [集数][段落编号][场景名]
空间真值调用中心 — [集数][段落编号][场景名]
```

`空间真值调用中心 — [集数][段落编号][场景名]` 是独立物理节点，不是场景调度表附录。

场景调度表只记录影响空间调度的中文角色全名、状态、坐标、视线、相对距离和运动轨迹；角色名称字段必须逐字继承剧本 / A0 / A1 的中文角色全名，不得短名化、缩写化或 token 化。人物面部三庭五眼、皮肤瑕疵、骨相、服装材质保存在 A1，不在 A2 重复粘贴。

场景调度表必须从 A0 抽取并包含：故事板概要引用记录、冲突修复记录、Global Environment Context、场景空间结构、角色站位表、道具坐标表、Eyeline Map、Panel 动作关键帧列表、Panel Character Spatial Matrix、镜头组使用规则、视频提示词继承规则、`dialogue_intent_delivery_matrix` 继承记录、`video_model_capability_risk_register` 继承记录、`performance_substitution_plan` 执行记录、人物参考图清单、场景参考图清单、关键道具参考图清单、可选光影参考图清单。

A2 的 Panel 动作关键帧、道具坐标表和 `[Temporal_Anchor]` 必须继承 A0/A1 的替代表现方案。对“画叉否定方案”这类高风险动作，可拆成笔尖压纸起势、纸面已出现红叉结果、笔尖摩擦声打点、被否定者反应等稳定镜头锚点；禁止要求视频模型在同一连续镜头中准确实时画出指定符号。

## 空间真值字段

`空间真值调用中心` 必须包含独立小节 `坐标与摄影机基准`。该小节是 A4 舞台定位图、B1-B5 黑白分镜和 B6-B8 视频提示词的共同几何源，不得只散落在角色站位表或 Panel 描述里。`坐标与摄影机基准` 必须逐 Panel 写明：`panel_id`、`coordinate_system: 100x100, origin_top_left`、`stage_origin_note`、`scale_note`、`role_coordinate_baseline`、`prop_coordinate_baseline`、`camera_baseline`、`screen_direction_baseline`、`reference_validity_chain`。

所有坐标禁止写成裸数字或无键数组。二维坐标必须使用对象格式：`{"x": <number>, "y": <number>}`；三维坐标必须使用对象格式：`{"x": <number>, "y": <number>, "z": <number>}`。例如 `stage_position_xy: {"x": 42, "y": 66}`、`stage_position_xyz: {"x": 42, "y": 66, "z": 0}`、`camera_position_xyz: {"x": 42, "y": -18, "z": 12}`。禁止写 `42,66`、`[42,66]`、`42/-18/12` 或只有数字没有 X/Y/Z 键名的形式。为避免 A4/B1-B5 传递时产生歧义，A2 的每个角色和每个道具都必须同时写入 `stage_position_xy` 与 `stage_position_xyz`；平面舞台对象默认 `z: 0`，多层空间、楼梯、平台、桌面上下层必须写真实高度层级。若旧链路产出数组、裸数字、只有二维无三维或缺少 X/Y/Z 键名，必须在进入 A4 前标准化为对象格式并回写。

角色站位表单兵字段：`角色`、`identity_token`、`stage_position_xy`、`stage_position_xyz`、`facing_target_xy`、`facing_target_xyz`、`screen_position`、`screen_direction_text`、`spatial_direction_text`、`facing_direction_text`、`camera_facing`、`camera_position_xyz`、`camera_target_xyz`、`camera_direction_text`、`camera_screen_position_text`、`focal_length_mm`、`eyeline`、`distance_relation`、`movement_path`、`movement_path_xyz`、`movement_direction_text`、`state_action`、`previous_emotion_state`、`current_emotion_state`、`next_emotion_target`、`visibility_state`。其中所有 `_text` 字段必须是从同一组 `stage_position_xyz`、`facing_target_xyz`、`camera_position_xyz`、`camera_target_xyz`、`screen_position` 推导出的自然语言方位描述，禁止另行编造。

每个 Panel 的空间真值必须同时生成摄影机三维字段：`camera_position_xyz`、`camera_target_xyz`、`focal_length_mm`、`camera_facing`。`camera_position_xyz` 与 `camera_target_xyz` 必须为带 X/Y/Z 键名的 JSON 对象 `{"x": number, "y": number, "z": number}`，`focal_length_mm` 必须为数字焦段值；禁止只写“镜头看向角色”“对准冲突中心”等自然语言。

`[Temporal_Anchor]` 属于 Panel 级全局刚性时序约束，必须作为与 `Role List` 平级的独立全局对象置于每个 Panel 顶层。格式：

```text
Temporal_Anchor: { panel_duration: <秒数>, key_action_timestamp: <秒数>, sfx_trigger_point: <文本>, sfx_frequency: <文本>, low_frequency_peak: <秒数或无>, impact_sound_peak: <秒数或无>, dialogue_speed_constraint: <文本>, sound_rhythm_constraint: <文本> }
```

情感字段必须形成 Character State Machine。后一 Panel 的表演只能从前序情绪逻辑过渡，禁止随机跳变。单人或多人动作统一使用数组：

```text
key_action_timestamps: [{ identity_token: <Token>, action_offset: <秒数>, target_emotion: <情感> }]
```

禁止使用单值非数组的 Scalar 变体。

## 空间矩阵

`Panel Character Spatial Matrix` 必须使用 100x100 坐标系，`Layout Grid: 100x100 coordinate system, (0,0) is top-left`。所有矩阵坐标必须使用带键对象 `{"x": number, "y": number}`；含高度 / 摄影机 / 多层空间时必须使用 `{"x": number, "y": number, "z": number}`。`Eyeline Map` 必须使用 `[发射源角色 -> 接收目标对象: 视线角度/朝向向量]`。生成任何 Panel 脚本前必须执行 `[REQUIRED PRE-GENERATION STEP: SPATIAL MATRIX]`，列出 ALL characters 的 Character Nodes、Eyeline Vectors、Gaze Target、Gaze Angle，并做 Consistency Check。

## A2 Exit Guard

A2 结束后必须验证 `空间真值调用中心 — [集数][段落编号][场景名]` 存在且包含：`坐标与摄影机基准`、`Panel Number`、`Role List`（每个条目必须含 `Name`、`stage_position_xy: {"x": number, "y": number}`、`stage_position_xyz: {"x": number, "y": number, "z": number}`）、`Prop List`（每个道具条目同样必须含 `prop_token`、`stage_position_xy`、`stage_position_xyz`）、`Focus Target`、`Eyeline Matrix`、`Blocking Logic`、`[Temporal_Anchor]`、`key_action_timestamps` 数组、`camera_position_xyz`、`camera_target_xyz`、`focal_length_mm`、`camera_facing`、`screen_direction_text`、`spatial_direction_text`、`facing_direction_text`、`camera_direction_text`、`camera_screen_position_text`、`movement_path_xyz`、`movement_direction_text`、`dialogue_delivery_mode_payload`、`model_capability_risk_payload`、`performance_substitution_payload`。`[Temporal_Anchor]` 必须包含 `panel_duration`、`key_action_timestamp`、`sfx_trigger_point`、`sfx_frequency`、`low_frequency_peak`、`impact_sound_peak`、`dialogue_speed_constraint`、`sound_rhythm_constraint`。所有坐标字段必须是带 `x/y/z` 键名的 JSON 对象；二维字段必须显式使用 `stage_position_xy`，三维字段必须显式使用 `stage_position_xyz`，平面对象默认 `z: 0`；不得出现裸数字、数组、逗号字符串、散文位置或只有二维无三维的角色/道具坐标。所有 `_text` 字段必须能回溯到同一组坐标 / 朝向 / 摄影机数值字段；若自然语言方位与数值字段冲突，以数值字段为准并立即回写修正 `_text` 字段。若仍包含未经 A0 登记或未经替代的高风险精细动作，触发 `[E01: Missing Script/Assets]` 或回 A0/A1 重写替代表现方案，禁止进入 A3/B1。

若缺失或字段不全，触发 `[E01: Missing Script/Assets]`，禁止进入 A3。A1 故事板概要、A2 场景调度表或空间真值调用中心通过 QC 后若未写入 `core_doc_freeze_records` / `chain_freeze_manifest`，或缺少 `freeze_id` / `content_hash_or_length_snapshot` / `allowed_mutation_scope` / `upstream_freeze_ids`，触发 `[E08: Chain Freeze Violation]`，禁止进入 A3/A4/B1-B5。

A2 结束后必须执行 `Narrative Capacity Recalibration`：回读 A1 故事板概要、A2 场景调度表、`空间真值调用中心` 的 Panel Character Spatial Matrix、`[Temporal_Anchor]`、角色状态、道具状态、Blocking Logic 与 Focus Target，重新校准 A0 的 `SSC Narrative Capacity Engine` 和 `视频任务切分计划`。若校准结果与 A0 初算不一致，必须 `hub_edit` 回写 `影视工业体系数据中心 — [集数][段落编号][场景名]`；若校准结果与初算一致，也必须在 A0 中记录 `Narrative Capacity Recalibration: completed`。两种情况都必须清除 `Narrative Capacity Recalibration Pending`。A2 与空间真值通过 Exit Guard 后，必须把 `场景调度表 — [集数][段落编号][场景名]` 与 `空间真值调用中心 — [集数][段落编号][场景名]` 写入 A0 `[SSC_RUNTIME_LEDGER].core_doc_freeze_records` 与 `chain_freeze_manifest`：冻结 Panel Character Spatial Matrix、`坐标与摄影机基准`、`Temporal_Anchor`、角色 / 道具坐标、Eyeline、Blocking Logic、camera_position_xyz、camera_target_xyz、focal_length_mm、全部 `_text` 方位字段、`dialogue_delivery_mode_payload`、`model_capability_risk_payload`、`performance_substitution_payload`。A2 / 空间真值的 `freeze_id` 必须回填到所有受影响 `video_task_mapping[video_task_id].stage_freeze_ids`。同时 A2 必须逐个 `video_task_id` 回写 A0 `video_task_mapping[video_task_id].reference_requirements.required_scene_asset_ids`、`required_character_identity_tokens`、`required_prop_tokens`、`required_lighting_reference`、`required_storyboard_grid`、`forbidden_video_inputs`、`producer_stage: A0/A2`、`consumer_stage: A4/B1-B5/B6-B8`，并把这些字段登记进 `upstream_producer_map` 与 `downstream_consumer_map`；若任一任务的参考需求仍为空、`coverage_status` 被写成 PASS、或未记录 producer / consumer，触发 `[E13: Link Interface Contract Failure]` 或 `[E14: Empty Upstream Data / Pending-as-PASS Failure]`，禁止进入 A3/A4。后续 A4/B1-B8 只能从冻结版本继承，若坐标、朝向、时序、对白交付、能力边界载荷或参考需求接口需修正，必须生成版本化补丁和新 freeze_id，不得原地覆盖。若新增 / 拆分视频任务，后续 A4/B1-B8 必须按新任务编号重新生成对应资产，并重新初始化 / 回写该任务的 `reference_requirements`、`upstream_producer_map`、`downstream_consumer_map` 与 `link_interface_audit_status`，不得沿用旧任务映射。

若 table_node 生成期间修正坐标、Z-index、朝向或 `facing_target_xy`，必须同步 `hub_edit` 回写 `空间真值调用中心 — [集数][段落编号][场景名]` 的 `坐标与摄影机基准`、Panel Character Spatial Matrix 和对应角色 / 道具字段，再重新执行 `Narrative Capacity Recalibration` 和 A5 退出自检。若发现任何坐标仍为裸数字、无键数组或缺少 X/Y/Z 键名，必须先标准化并回写，禁止进入 A4/B1。
