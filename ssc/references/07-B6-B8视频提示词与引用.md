# B6-B8 视频提示词与引用

本文件由 `00-强制读取索引.md` 强制触发。进入 B6-B8 或视频生成前必须读取本文件；未读取即触发 `[E07: Required Reference Missing]`。

## B6 主文档

只生成 / 更新一个主文档：

```text
视频提示词列表.md
```

生成前必须读取 A0，并继承 `视频任务切分计划`、`dialogue_source_lock.required_dialogues`、`task_dialogue_inventory`、`dialogue_intent_delivery_matrix`、`video_output_format_lock`、`video_model_capability_risk_register`、`performance_substitution_plan`、Seedance 标准模板字段、A3 `scene_cinematography_profile`、ARRI ALEXA 65 参数、FACS/AU、身体语言、镜头、光影、声音和 QC 最低落地要求。B6/B8 的最终视频比例、时长、模型和声音开关只能来自 A0 `video_output_format_lock` 或用户明确覆盖记录，不得从 A3/A4/B1-B5 参考资产物理比例继承。

**B6-B8 入口 A3/A4/B1 同源完整性锁**：进入 B6、B8 或视频派发前，必须验证当前 `video_task_id` 的冻结链包含同一个 PASS 版本的 `A3_SCOPE_MANIFEST.freeze_id`，并满足：A3 manifest `a3_completion_status: PASS`、A4 `source_a3_scope_manifest_freeze_id` 与其一致、A4 生成晚于该 A3 manifest、B1-B5 `source_a3_scope_manifest_freeze_id` 与其一致、B1-B5 消费的是该 A4 的 ACTIVE 冻结版本。若 A3 manifest 缺失 / 失败 / task_only 未经用户明确授权，或 A4/B1-B5 任一产物早于有效 A3 manifest、引用旧 A4、引用被 E16 隔离的污染产物，立即触发 `[E16: A3 Asset Completion Barrier Failure]`，禁止生成 / 编译 / 派发视频提示词，必须回到 A3 补齐并重新生成 A4 与 B1-B5。

无论半自动还是全自动，B6-B8 必须根据前序剧情和当前视频任务需要加载用户自建外部 Skill 能力优化提示词。外部 Skill 优化完成后的 `视频提示词列表.md` 段落、[Panel Execution Chain]、[Visual Block]、[Audio Hook]、[Camera Block]、Feature Decoupling Guard 和冻结后的剧情 / 表演 / 声音 / 镜头主体内容立即冻结。B8 正式派发给视频模型前，只允许把这些冻结内容按“最终视频模型纯提示词模板最高铁律”编译成自然语言纯提示词；该编译只能改变外层格式和引用写法，不能修改、压缩、精简、提炼、缩减、概括、重写、截断、删减或合并同义句。提示词文本长度本身不是限制条件，不能因为提示词长而拆分、改写或删减。

冻结必须有机器可检查记录：B6 完成外部 Skill 优化后，必须在 `视频提示词列表.md` 当前任务段写入 `[PROMPT_FREEZE_RECORD]`，并同步写入 A0 `[SSC_RUNTIME_LEDGER].video_task_mapping[video_task_id].prompt_freeze_record`、`[SSC_RUNTIME_LEDGER].core_doc_freeze_records` 和 `[SSC_RUNTIME_LEDGER].chain_freeze_manifest`。记录字段必须包含：`freeze_status: frozen`、`freeze_id`、`stage: B6`、`frozen_blocks: [Visual Block, Panel Execution Chain, Audio Hook, Camera Block, Feature Decoupling Guard, task_description]`、`freeze_after_external_skills`、`frozen_at`、`upstream_freeze_ids`、`content_hash_or_length_snapshot`、`allowed_mutation_scope: [@IMAGE_ASSET_N 动态重索引, 视频参考图引用映射, Reference image paths order, B8 纯提示词格式编译]`、`allowed_post_freeze_mutations: [@IMAGE_ASSET_N, 视频参考图引用映射, Reference image paths order]`。B6 `freeze_id` 必须同步回填到当前 `video_task_mapping[video_task_id].stage_freeze_ids` 或 `dispatch_payload_freeze_ids`，让 B8 能从任务映射索引追溯到提示词工作文档冻结快照。缺少该记录或缺少任务映射索引时，视为未冻结，禁止进入 B7/B8，并触发 `[E08: Chain Freeze Violation]`。

冻结规则不禁止机器引用层修正。B8 因 9 张上限、资产合并或 `image_paths` 顺序变化而执行动态重索引时，只允许修改 `@IMAGE_ASSET_N` 编号、`Video Reference Mention Map / 视频参考图引用映射` 和对应真实路径顺序；不得修改、压缩、重写、删减任何剧情、镜头、表演、声音、Panel Execution Chain 主体文本或节奏时间码。

每个 10-15 秒视频任务必须在 `视频提示词列表.md` 中拥有独立提示词段，并一一绑定该任务的舞台定位图、黑白 3x3 分镜图、参考图和时间码。每段必须按 `Panel 1 -> Panel 2 -> Panel 3 -> Panel 4 -> Panel 5 -> Panel 6 -> Panel 7 -> Panel 8 -> Panel 9` 的顺序写成连续视频执行链，逐 Panel 继承黑白分镜里的取景、站位、运动链、镜头方向、`Temporal_Anchor`、角色状态变化、`screen_direction_text`、`spatial_direction_text`、`facing_direction_text`、`camera_direction_text`、`camera_screen_position_text`、`movement_direction_text` 和道具方位字段。禁止一个提示词段覆盖多个视频任务。

## Panel 顺序执行链

每个视频任务段必须包含 `[Panel Execution Chain]`，按 Panel 1 至 Panel 9 顺序列出 9 个时间片。每个时间片必须包含：`panel_id`、`time_range`、`source_panel_from_storyboard_grid`、`storyboard_grid_position`、`source_coordinate_camera_baseline_section: 坐标与摄影机基准`、`role_spatial_state`、`prop_spatial_state`、`camera_spatial_status`、`stage_map_shape_color_payload`、`direction_text_payload`、`character_count_lock_payload`、`action_transition_from_previous_panel`、`dialogue_delivery_mode_payload`、`model_capability_risk_payload`、`performance_substitution_payload`、`audio_or_sfx_anchor`、`continuity_to_next_panel`。`stage_map_shape_color_payload` 必须逐 Panel 从 A4 table_node 与 B1-B5 `[Stage Map Same-Source Spatial Payload]` 继承 `character_shape_color_map`、`prop_shape_color_map`、人物 `shape: square`、道具 `shape: circle`、`color_name`、`color_index`、`stage_position_xy`、`stage_position_xyz`，仅作为身份 / blocking / 道具对应关系的结构化真值，不得要求最终彩色视频出现色块、框线或标签文字。`role_spatial_state`、`prop_spatial_state`、`camera_spatial_status` 中的所有坐标必须保持 `{"x": number, "y": number}` 或 `{"x": number, "y": number, "z": number}` 对象格式；角色和道具必须同时保留 `stage_position_xy` 与 `stage_position_xyz`，平面对象默认 `z: 0`；若存在运动轨迹，必须同时保留 `movement_path` 与 `movement_path_xyz`，禁止裸数字、无键数组、逗号字符串、散文位置或只有二维无三维。`direction_text_payload` 必须继承 `screen_direction_text`、`spatial_direction_text`、`facing_direction_text`、`camera_direction_text`、`camera_screen_position_text`、`movement_direction_text`、`prop_spatial_direction_text`、`prop_movement_direction_text`，并与同一 Panel 的坐标 / 摄影机数值字段一致。`source_panel_from_storyboard_grid` 必须绑定当前任务自己的 `@STORYBOARD_GRID` 对应 Panel，并同时记录该 Panel 从 A2 `坐标与摄影机基准` / table_node 继承的同源空间字段；禁止只写“参考第 X 格”。`storyboard_grid_position` 必须写明 3x3 中的行列位置：Panel 1=row1 col1、Panel 2=row1 col2、Panel 3=row1 col3、Panel 4=row2 col1、Panel 5=row2 col2、Panel 6=row2 col3、Panel 7=row3 col1、Panel 8=row3 col2、Panel 9=row3 col3。正式视频 task_description 必须要求模型从 Panel 1 开始推进到 Panel 9，禁止跳 Panel、重排 Panel、只抽取某一格、或把 9 格融合成一个泛化自然语言镜头。

9 个 `time_range` 必须连续覆盖当前视频任务完整时长，从 0 秒开始到任务总时长结束；禁止重叠、跳秒、倒序、空洞或总时长不一致。`time_range` 分配必须由 A2 `[Temporal_Anchor]`、动作密度、台词长度、情绪停顿、声音节奏和转场损耗共同决定，不得机械平均。若 9 个 Panel 无法在 10-15 秒内被观众读懂，禁止压缩提示词或删减 Panel，必须回到 A0 `视频任务切分计划` 拆成更多 10-15 秒视频任务，并为新增任务重新生成舞台定位图、黑白 3x3 分镜图和独立提示词段。

## B8 最终视频模型纯提示词模板最高铁律

B6 工作文档可以保留 `[Visual Block]`、`[Panel Execution Chain]`、`[Audio Hook]`、`[Camera Block]`、`[PROMPT_FREEZE_RECORD]`、QC 和账本字段；但 B8 正式派发给视频模型的最终 `task_description` 必须重新编译为一段可直接给视频模型执行的纯提示词，结构必须严格采用以下模板，不得把 SSC 内部块标题、YAML/JSON 结构、QC、冻结记录、Required_References_Read 或账本字段原样塞给视频模型。

**编译边界硬锁**：B8 的“纯提示词编译”只允许做格式编译与机器引用层展开，禁止改写冻结创作内容。允许行为包括：删除 SSC 内部字段名、把结构化字段按原意展开成自然语言、把 `@IMAGE_ASSET_N` 替换为最终 `@文件名`、把 `video_output_format_lock` 的模型 / 比例 / 时长 / 声音字段放到开头。禁止行为包括：改写台词、删减镜头、合并动作、压缩表演、改变镜头顺序、改变时长、改变比例、改变角色 / 道具 / 空间真值、改变声音策略、把对白换成旁白或沉默反应。若无法在不改写内容的情况下编译，必须停止并回到 B6 或 A0 拆分任务，不得“自然语言优化”。

**输出比例唯一来源**：模板中的 `ratio:` 必须等于 A0 `video_output_format_lock.final_video_aspect_ratio`，默认 `9:16`。A3/A4/B1-B5 的 16:9 只代表参考资产 / 舞台图 / 分镜板画布比例，不得继承为最终视频比例。B8 派发前必须生成 `video_output_format_check`：

  a0_lock_model: <A0.video_output_format_lock.final_video_model>
  final_prompt_model: <B8 final_video_model_prompt_text 第一行 model>
  wrapper_model: <video_agent_verbatim_wrapper 内部第一行 model>
  actual_dispatch_model: <正式派发 video agent 的 model>

正式生成视频前，用一次 `question` 弹窗完成单次事务确认：增强选择、确认 `视频提示词列表.md` 基础内容、授权同轮视频生成。用户选择后，不再回写文档触发第二轮自检，直接把增强选择注入同一轮最终视频模型 dispatch 参数。用户原话包含“全自动”时，跳过本次 B7 弹窗，自动采用本 Skill 推荐增强选择、默认确认 `视频提示词列表.md` 基础内容并授权同轮视频生成；仍必须完成视频引用可解析性预检。

B7 授权必须写入 A0 `[SSC_RUNTIME_LEDGER].question_authorization_log` 与 `[SSC_RUNTIME_LEDGER].video_task_mapping[video_task_id].b7_authorization`。记录字段必须包含：`authorization_mode: question | full_auto`、`enhancement_choice`、`prompt_doc_confirmed: true`、`same_round_video_generation_authorized: true`、`authorized_at`、`authorized_video_task_id`、`high_risk_override: false`。若模型不可用 / 需换模型、引用解析失败、连续 3 次 FAIL 或安全风险发生，必须另开高危 `question` 并写入同一日志，不能复用 B7 常规授权。

## B8 9 张上限与阶梯合并

视频模型底层输入通道上限为 9 张。派发前计算真实参考图总数：人物 N + 场景 M + 关键道具 K + 分镜 1 + 可选光影 L。禁止把舞台定位图计入视频模型输入。

若总数 > 9，先通过 `question` 提醒用户触发超限拦截，再按低叙事权重到高叙事权重阶梯合并：关键道具 -> 场景 -> 人物。用户原话包含“全自动”时，不弹窗提醒，直接按该阶梯自动合并；若自动合并后仍无法降至 9 张以内，触发高危 `question` 请求人工删减或重组参考图。

合并必须是网格无损拼接，严禁层叠、融合或裁切。角色 / 道具合并参考图必须沿用 A3 彩色框选与中文名称标签协议；这些框线与标签只服务识别，进入视频 `参考图使用规则` 时必须声明最终画面不得出现框线、文字、色块、宫格或参考图排版。合并图最终画布必须归一化为 16:9；不满足则用纯黑 Black Padding。

只有物理 `Reference image paths` 数量 <= 9 且所有合并大图均为 16:9，才可进入视频生成。
