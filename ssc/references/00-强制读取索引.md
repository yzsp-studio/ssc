# 强制读取索引

本目录不是可选资料库，而是 `ssc` 的阶段执行契约。任何进入对应阶段的动作，必须先真实调用 `hub_read` 读取本索引和阶段 reference；未读取即视为 Entry Guard 未完成，必须熔断。

## 读取总则

1. 链路启动、恢复、重做、局部修复、视频前确认前，必须先读取本文件。
2. 每个阶段进入前必须读取对应 reference 文件，不能只依赖 SKILL.md 摘要、对话历史或旧缓存。
3. reference 文件读取失败、路径不存在、内容为空、版本不明，立即触发 `[E07: Required Reference Missing]`，暂停链路并通过 `question` 弹窗让用户选择修复、暂停或回退。
4. 每次阶段派单必须在任务包里写入 `[Required_References_Read]`，记录本次读取过的 reference 文件名。
5. references 触发不是语义判断，不看关键词；只由制作阶段决定。

## 防漏读断言

- 如果一个阶段需要多个 reference，必须全部读取，不允许“读过类似内容”替代。
- 子阶段不能继承上阶段的读取记录，除非当前动作仍在同一次未中断事务内。
- 任何 `question` 授权后进入下一制作动作时，必须重新执行本阶段硬读取。
